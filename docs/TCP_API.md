# TLS/TCP 用户接口

用户客户端从 0.3.0 起不再连接公网 HTTP API，而是直接连接服务端的 TLS/TCP 端口。

- 默认监听：`0.0.0.0:17889`
- 传输加密：TLS 1.2/1.3
- 消息格式：4 字节大端无符号长度 + UTF-8 JSON
- 最大单帧：256MB
- 连接上限：200；同一来源登录/注册最多 20 次/分钟
- 参考图：最多 10 张，总原始大小最多 120MB
- 视频：由服务端读取并通过 TCP 返回，客户端保存为 `.mp4`

服务端首次启动会在本地生成独立的自签名证书。客户端首次连接采用 TOFU 方式保存 SHA-256 指纹，后续连接如发现指纹改变会直接拒绝，需要向服务提供方核对后手动点击“重置信任”。

普通用户无需知道管理端 API Key。注册、登录、积分、生成任务、状态轮询和视频下载都使用 TCP action：

- `health`
- `register`
- `login`
- `logout`
- `me`
- `credits`
- `requests`
- `generate`
- `request.get`
- `video.get`

Windows 服务端需要在防火墙放行所配置的 TCP 端口；如果经过路由器或云服务器，还需要设置 TCP 端口映射。普通 HTTP 反向代理不能转发此协议，应使用四层 TCP 转发。
